## Java 是静态类型语言：
### 变量和基本数据类型

| Java      | 含义   | Python 类似 |
| --------- | ---- | --------- |
| `int`     | 整数   | `int`     |
| `double`  | 小数   | `float`   |
| `boolean` | 布尔值  | `bool`    |
| `char`    | 单个字符 | 没有完全对应    |
| `String`  | 字符串  | `str`     |
